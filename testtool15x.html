📍 區塊 1：A/B/C 的相對位置 哪個最大？

怎麼看：「A>B>C」代表 A 最大、C 最小 時的結果分布。綠色多 = 常出現 H（主勝），黃色 = D（和局），紅色 = A（客勝）。

📈 區塊 2：A − C 差值分析 主勝率 − 客勝率

A − C = 主勝率減客勝率。正值大 = 主隊強；負值大 = 客隊強；接近 0 = 雙方接近（可能和局）。

📈 區塊 3：A − B 差值分析 主勝率 − 和率

A − B = 主勝率減和率。正大 = 主隊明顯強於和局。

📈 區塊 4：B − C 差值分析 和率 − 客勝率

B − C = 和率減客勝率。正大 = 和局可能高於客勝。
