🪄 懒人包 — 一鍵抓取數據

貼上網址或 HTML → 自動偵測 → 一鍵複製 → 貼進優化器

📖 兩種用法：
方法 1（有網址）：貼上網址 → 按「🌐 抓取網頁」→ 自動分析
方法 2（iPhone 或其他）：在 Safari 打開網頁 → 網址列打 view-source: 開頭 → 複製全部 → 貼下方
📋 或直接貼 HTML：
👁 偵測結果預覽
✅ 生成結果
💡 詳細說明
1
複製網頁 HTML
電腦：按 F12 → Elements 面板找最上面 <html> → 右鍵 → Copy → Copy outerHTML
iPhone Safari：網址列打 view-source:網址 → 全選複製
iPhone Chrome：用第三方 App「Codeye」或「View Source」
2
貼到上方文字框
直接 Ctrl+V 貼上，或按上方「🌐 抓取網頁」自動抓
3
按「⚡ 自動分析並生成」
工具會自動找出所有表格，並轉成優化器需要的格式（每行：A B C D E F 比分 結果）
4
複製結果 → 貼進優化器
按「📋 一鍵複製」→ 到 v15 優化器貼上 → 開始搜尋
⚠
如果抓不到
網頁若用 JavaScript 動態載入，靜態 HTML 抓不到數據。此時請：
1. 用 F12 抓完整 DOM（因為 DOM 已包含 JS 生成的內容）
2. 或用電腦版 Chrome 的「Copy outerHTML」
