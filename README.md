# 專屬預測器 (Poisson + 能力值)

一個純前端、單檔 HTML 的足球賽事預測工具。以 Poisson 分佈為核心，結合場均得失、市場賠率、球隊狀態與排名，輸出比分機率、賽果預測、大細判斷與球隊能力值雷達圖。無需後端、無需安裝、無需建置，直接用瀏覽器打開即可使用。

## 功能特色

- **Poisson 比分矩陣**：以 0~10 球建立主客隊入球機率矩陣，計算所有比分機率並正規化。
- **市場賠率整合**：輸入 1X2 賠率後自動放大 λ，並同步調整攻防能力值；未填賠率則為純數據模式。
- **單條賽果橫條**：主勝（紅）／和局（灰）／客勝（藍）堆疊成一條，箭嘴固定指向 50% 中位，指中哪段即為預測結果。
- **前四比分預測**：列出最可能的前 4 個比分，附入球大／小、BTTS 標籤與星級（金／銀／銅）。
- **雙選球隊入球數**：主客隊各自最可能的兩個入球數，並標示首選。
- **各隊大細與總入球大細**：完全由 Poisson 機率判定（門檻 70%），非人工規則。
- **完整比分分佈 Top 10**：可滾動表格，附標籤、星級與機率。
- **能力值與雷達圖**：進攻、防守、狀態、賠率、排名五維評級（E~S），並計算整體戰力；主隊紅色、客隊藍色雷達。
- **狀態與排名徽章**：狀態 0~3 分級顯示（極差～極好），排名前三名有金／銀／銅發光效果。
- **上盤／下盤標示**：依主客賠率自動標示。
- **一鍵截圖保存**：內建 html2canvas，可分別保存「預測」、「分佈」、「分析」三張圖，手機長按即可存相簿。
- **輸入自動正規化**：自動過濾非數字字元、處理小數點、將 `121` 轉為 `1.21` 等。
- **深色主題**：適合長時間閱讀與截圖分享。

## 使用方式

1. 下載或複製 `index.html`。
2. 用任何現代瀏覽器（Chrome / Safari / Edge / Firefox）打開。
3. 填寫資料後按「開始預測」。
4. 結果區可分別截圖保存。

若按「清除」會清空所有輸入並隱藏結果區。

## 輸入欄位說明

| 欄位 | 必填 | 說明 |
|---|---|---|
| 場均得分 | ✅ | 該隊平均每場入球 |
| 場均失球 | ✅ | 該隊平均每場失球 |
| 狀態 (0-3) | 選填 | 0 = 極差、3 = 極好，可輸入小數 |
| 排名 | 選填 | 聯賽排名（整數） |
| 主/和/客賠率 | 選填 | 市場 1X2 賠率，需三者皆 > 1 |

**能力值與雷達圖顯示條件**：狀態、排名、賠率三者全部填寫才會顯示；否則整塊隱藏，「保存分析」按鈕也一併隱藏。

**賠率模式**：三個賠率皆有效（> 1）才視為有賠率；否則為純數據模式，λ 不放大。

## 計算邏輯

### 1. 基礎 λ（期望入球）

```
baseLH = (主隊場均得分 + 客隊場均失球) / 2
baseLA = (客隊場均得分 + 主隊場均失球) / 2
```

兩者皆夾在 `0.05 ~ 6` 之間。

### 2. 賠率放大 λ

若有輸入賠率：

```
ratioH = sqrt(oddD / oddH)
ratioA = sqrt(oddD / oddA)
lH = clamp(baseLH * ratioH, 0.05, 6)
lA = clamp(baseLA * ratioA, 0.05, 6)
```

實際用於能力值的比例為 `lambdaRatio = lH / baseLH`（即經夾取後的真實倍數）。

### 3. Poisson 比分矩陣

對 `i, j ∈ [0, 10]`：

```
P(i, j) = Poisson(i; lH) × Poisson(j; lA)
```

其中 `Poisson(k; λ) = e^(-λ) × λ^k / k!`。所有 `P(i, j)` 加總後正規化（除以總和），再統計：

- 主勝（i > j）／和局（i = j）／客勝（i < j）機率
- 大 2.5（i + j ≥ 3）／細 2.5
- BTTS（i > 0 且 j > 0）
- 主隊入球數分佈 `hGoalProbs[i]`
- 客隊入球數分佈 `aGoalProbs[j]`
- 總入球分佈 `totalGoalProbs[i + j]`
- 最終期望入球 `final_lH = Σ i × P(i,j)`、`final_lA = Σ j × P(i,j)`

**排序規則**：先依機率由高到低；機率相同時，主隊為熱門則主勝比分優先，否則客勝比分優先。

### 4. 賽果預測（單條堆疊橫條）

將主勝、和局、客勝正規化為總和 100%（`normalizeTo100`，誤差補到最大項），堆疊成一條橫條：

- 左：主勝（紅 `#e5484d`）
- 中：和局（灰 `#6b7280`）
- 右：客勝（藍 `#4da3ff`）

箭嘴固定指向 50% 中位，判斷邏輯：

```
若 50 < 主勝%          → 預測主勝
若 50 ≥ 主勝% + 和局%  → 預測客勝
否則                   → 預測和局
```

橫條內不顯示文字，百分比顯示在下方圖例。

### 5. 大細判定（門檻 70%）

**球隊大細**（依主或客隊入球分佈）：

| 條件 | 判定 |
|---|---|
| P(3+) ≥ 70% | 2.5 球 大 |
| P(0) ≥ 70% | 0.5 球 細 |
| P(2+) ≥ 70% | 1.5 球 大 |
| P(2+) ≤ 30% | 1.5 球 細 |
| 其他 | 模糊 |

**總入球大細**（依總入球分佈）：

| 條件 | 判定 |
|---|---|
| P(4+) ≥ 70% | 3.5 球 大 |
| P(≤1) ≥ 70% | 1.5 球 細 |
| P(3+) ≥ 70% | 2.5 球 大 |
| P(≤2) ≥ 70% | 2.5 球 細 |
| 其他 | 模糊 |

### 6. 能力值公式

**基礎值**（未計賠率）：

```
進攻 = clamp(場均得分 / 3 × 100, 0, 100)
防守 = clamp((3 - 場均失球) / 3 × 100, 0, 100)
```

即攻入 3 球＝進攻滿分，失 0 球＝防守滿分。

**有賠率時**（溫和版全乘法）：

```
soften = 0.5 + 0.5 × lambdaRatio
進攻 = clamp(進攻 × soften, 0, 100)
防守 = clamp(防守 × soften, 0, 100)
```

被看好（`ratio > 1`）攻守皆升、被看淡（`ratio < 1`）攻守皆降，數值平滑不爆滿。

**其他維度**：

- 狀態 = `clamp(狀態值 / 3 × 100, 0, 100)`
- 賠率 = `對手賠率 / (主賠 + 客賠) × 100`（無賠率時為 50）
- 排名 = `對手排名 / (主排名 + 客排名) × 100`（無排名時為 50）

**整體戰力**：

- 有排名：`(進攻 + 防守 + 狀態 + 賠率 + 排名) / 5`
- 無排名：`(進攻 + 防守 + 狀態 + 賠率) / 4`

**風格判定**（依進攻 − 防守差值）：

| 差值 | 風格 |
|---|---|
| ≥ +25 | 進攻型 |
| ≤ −25 | 防守型 |
| 其他 | 平衡型 |

**狀態徽章**：

| 狀態值 | 顯示 |
|---|---|
| ≤ 0.5 | 狀態極差（紅） |
| ≤ 1.0 | 狀態欠佳（淺紅） |
| ≤ 1.5 | 狀態一般（黃） |
| ≤ 2.0 | 狀態微優（黃綠） |
| ≤ 2.5 | 狀態良好（綠色發光） |
| > 2.5 | 狀態極好（青色發光） |

### 7. 評級對照（E ~ S）

| 百分比 | 評級 | 顏色 |
|---|---|---|
| < 25 | E | 紅 `#ff4d4d` |
| 25 ~ 49.9 | D | 銅 `#cd7f32` |
| 50 ~ 69.9 | C | 灰 `#c0c0c0` |
| 70 ~ 84.9 | B | 綠 `#4ade80` |
| 85 ~ 94.9 | A | 藍 `#4da6ff` |
| ≥ 95 | S | 金 `#FFD700` |

註：D 為銅色、C 為灰色（兩者已交換，非傳統順序）。

## 輸出區塊說明

**第 1 塊：預測（capture1）**

- 模式徽章：顯示賠率放大 λ 或純數據模式，以及攻防同步倍數。
- 前四比分卡片：首選～四選，含比分、機率、入球大／小／BTTS 標籤、星級。
- 雙選球隊入球數：主首選／主次選／客首選／客次選。
- 各隊大細：主隊大細、總入球大細、客隊大細（含 P 值）。
- λ 資訊：最終主／客期望入球。

**第 2 塊：分佈（capture2）**

- 最終賽果機率：單條堆疊橫條 + 中位箭嘴預測 + 圖例百分比。
- 完整比分機率分佈 Top 10：表格（#、比分、標籤、機率），可滾動。

**第 3 塊：分析（capture3，三者齊全才顯示）**

- 雷達圖：主隊（紅）、客隊（藍），軸為 ATK / DEF / STA / ODD / RNK（無排名時省略 RNK）。
- 能力值列表：進攻、防守、狀態、賠率、排名（各附評級與百分比）。
- 戰力徽章：整體評級與百分比。
- 風格徽章：進攻型／防守型／平衡型。
- 狀態徽章：狀態分級。
- 上盤／下盤徽章：依主客賠率。
- 排名徽章：第 N 名，前三名有金／銀／銅發光。

## 截圖功能

| 按鈕 | 內容 |
|---|---|
| 📸 保存預測 | 第 1 塊：前四比分、雙選入球、各隊大細、λ |
| 📸 保存分佈 | 第 2 塊：賽果橫條、Top 10 比分表 |
| 📸 保存分析 | 第 3 塊：能力值雷達圖與評級（三者齊全才顯示） |

截圖使用 html2canvas，`scale: 2`、背景色 `#222222`。生成後彈出預覽視窗，手機長按圖片即可儲存到相簿，桌面可右鍵另存。按「關閉」關閉視窗。

## 技術棧

- **純 HTML / CSS / JavaScript**：無框架、無建置步驟、無依賴套件管理。
- **html2canvas 1.4.1**：CDN 引入，用於將 DOM 截圖為 PNG。
- **SVG**：動態繪製雷達圖（多邊形網格、軸線、資料多邊形）。
- **CSS 動畫**：狀態與排名徽章的發光效果（`@keyframes glow-*`）。
- **響應式設計**：`@media(max-width:620px)` 將雙欄改單欄、四欄改兩欄。

## 注意事項

- 本工具為統計模型輔助，不構成任何投注建議。
- Poisson 模型假設主客隊入球獨立，未考慮傷停、天氣、賽程密度、主場優勢等即時因素。
- 賠率放大採用 `sqrt(和賠 / 該隊賠)` 啟發式做法，非嚴謹概率校準。
- 能力值公式中的「3 球」為滿分基準，屬設計選擇，非普適標準。
- 大細判定門檻固定 70%，未提供調整介面。
- 所有計算皆在瀏覽器本地完成，不上傳任何資料，無網路請求（除 CDN 載入 html2canvas）。
- 首次載入需網路連線以取得 html2canvas CDN；若離線使用，截圖功能將無法運作，其餘預測功能不受影響。
