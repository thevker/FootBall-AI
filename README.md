## 🎯 項目簡介

**xG 賽事分析器** 是一個單頁式網頁應用（SPA），專為足球賽事分析而設。透過輸入兩隊的數據，系統會即時計算出預測結果，並支援一鍵截圖保存。

> ⚠️ **工具只作娛樂分析，切勿沉迷賭博。**

## 📝 輸入數據說明

### 1. 極簡模式（預設關閉）
只需輸入 **主隊得分、主隊失球、客隊得分、客隊失球** 即可進行快速賽果與波膽預測。

### 2. 標準模式（預設開啟）
除了得分失球外，可輸入以下進階數據以獲得完整的實力分析：

| 欄位 | 說明 | 範例 | 備註 |
|---|---|---|---|
| **狀態** | 近期狀態評分 | `1.50` | 範圍 0 ~ 3，數值越高狀態越好 |
| **xG** | 預期入球 | `1.00` | 來自 FootyStats |
| **xGA** | 預期失球 | `1.00` | 來自 FootyStats |
| **排名** | 聯賽排名 | `1` | **選填**，兩隊都填才會啟用排名評分 |
| **賠率** | 賽前賠率 | `1.67` | 用於計算上下盤及賠率評分 |

> 💡 **提示**：所有數值欄位支援自動格式化，輸入 `15` 會自動變成 `1.50`，輸入 `150` 會變成 `1.50`。數據建議統一從 **[FootyStats](https://footystats.org/)** 匯入。

## 🧠 預測邏輯

### 1️⃣ 預測賽果（精確分界線）

系統核心公式：
`diff = (主隊得分 + 客隊失球) − (客隊得分 + 主隊失球)`

根據 `diff` 值對應賽果：

| diff 範圍 | 預測賽果 | 對應波膽池（淨勝球） |
|---|---|---|
| > 3.25 | 主勝(-2) | 淨勝 3 球 |
| 2.25 ~ 3.25 | 主勝(-1) | 淨勝 2 球 |
| 1.25 ~ 2.25 | 主勝 | 淨勝 1 球 |
| 0.15 ~ 1.25 | **和局/主勝** | — |
| -0.15 ~ 0.15 | **和局** | — |
| -1.25 ~ -0.15 | **和局/客勝** | — |
| -2.25 ~ -1.25 | 客勝 | 淨勝 1 球（客隊） |
| -3.25 ~ -2.25 | 客勝(-1) | 淨勝 2 球（客隊） |
| < -3.25 | 客勝(-2) | 淨勝 3 球（客隊） |

> ⚠️ 當出現「和局」、「和局/主勝」或「和局/客勝」時，系統會顯示警告提示，建議跳過該場賽事。

### 2️⃣ 入球大細（雙門檻法）

**主隊入球 1.5 / 客隊入球 1.5**：
- 若 `得分 ≤ 1.40` **且** `對方失球 ≤ 1.40` → **小**
- 若 `得分 ≥ 1.60` **且** `對方失球 ≥ 1.60` → **大**
- 其他情況 → **方向模糊**

**總入球 2.5**：
- 左右兩邊都是「小」→ **小 2.5**
- 左右兩邊都是「大」→ **大 2.5**
- 否則 → **方向模糊**

### 3️⃣ 波膽推薦（5x5 距離顏色網格）

波膽區塊採用 5x5 網格（00 至 44，顯示為 `0:0` 格式）。當滿足入球大細條件後，系統會根據比分淨勝球與「預測淨勝球」的差距上色：

- 🟢 **綠色**：距離 0（完全符合預測淨勝球）
- 🟡 **黃色**：距離 1（相差 1 球，極有可能發生）
- 🔴 **紅色**：距離 2（相差 2 球，存在可能性）
- ⚫ **灰色**：距離 > 2 或不符合大細條件（不建議）

*(例子：若預測為「主勝」且「主入球大」，綠色會是 2:1 / 3:2 / 4:3；黃色會是 2:0 / 3:1 / 4:2；紅色會是 3:0 / 4:1。)*

## 🏅 實力評級系統（標準模式限定）

系統會將每隊的指標轉換為 0~100 的百分比，並給出 E~X 等級：

| 指標 | 計算公式 | 顏色 |
|---|---|---|
| **進攻** | `(xG − 0.5) / 2.0 × 100` | 🔴 紅 |
| **防守** | `(3 − xGA − 0.5) / 2.0 × 100` | 🔵 藍 |
| **狀態** | `狀態 / 3.0 × 100` | 🟡 黃 |
| **賠率** | `客隊賠率 / (主 + 客賠率) × 100` | 🟢 綠 |
| **轉換** | `(得分 + 對方失球) / 轉換總和 × 100` | 🔵 螢光藍 |
| **排名** | `對方排名 / (主 + 客排名) × 100` | ⚪ 灰 |

**戰力總評**：六項指標平均，顯示格式為 **`戰力: A (84.8)`**。

## ❓ 常見問題

**Q: 需要密碼才能使用嗎？**  
A: 不需要。本工具目前完全免費，打開網頁即可直接使用，沒有任何時間限制。

**Q: 標準模式和極簡模式有什麼區別？**  
A: 「極簡模式」只需輸入得分與失球，適合快速預測；「標準模式」則需輸入完整數據，並會額外計算下方雷達圖與詳細戰力分析。

**Q: 為什麼波膽網格有綠色、黃色和紅色的格子？**  
A: 綠色代表「完全符合」預測的淨勝球；黃色和紅色代表「有差距但仍有可能發生」的比分（分別相差 1 球和 2 球），方便你進行多重防禦或判斷。

**Q: 轉換（COV）是什麼意思？**  
A: 主隊轉換 = 主隊得分 + 客隊失球；客隊轉換 = 客隊得分 + 主隊失球。反映進攻火力與對方防守漏洞的結合。
