## 🎯 項目簡介

**xG 賽事分析器** 是一個單頁式網頁應用（SPA），專為足球賽事分析而設。透過輸入兩隊的 **xG / xGA、場均得分、場均失球、近期狀態、賠率及聯賽排名**，系統會即時計算出：

- 🏆 **預測賽果**（主勝 / 客勝 / 讓球主勝 / 讓球客勝 / 不建議）
- ⚽ **入球大細**（主隊 1.5、總入球 2.5、客隊 1.5）
- 🎲 **波膽推薦**（精準比分組合，上限 3:3）
- 📊 **六角雷達圖** + **戰力評分**

整個工具**無需後端、無需安裝**，直接用瀏覽器開啟即可使用，並支援一鍵截圖保存分析結果。

> ⚠️ **工具只作娛樂分析，切勿沉迷賭博。**

- **xG / xGA**：Season Stats → xG For / xG Against
- **場均得分 / 失球**：Goals For / Goals Against (Per Match)
- **狀態評分**：可用近期 5 場勝率或自訂公式換算為 0~3
- **排名**：League Table 當前排名
- **賠率**：賽前 1X2 賠率

## 🧠 預測邏輯

### 1️⃣ 預測賽果（得失球碰撞法）

系統核心公式：

```
diff = (主隊得分 + 客隊失球) − (客隊得分 + 主隊失球)
```

根據 `diff` 值對應賽果：

| diff 範圍 | 預測賽果 | 對應波膽池（淨勝球） |
|---|---|---|
| ≥ 3.25 | 主勝(-2) | 淨勝 3 球 |
| 2.25 ~ 3.25 | 主勝(-1) | 淨勝 2 球 |
| 1.25 ~ 2.25 | 主勝 | 淨勝 1 球 |
| **-1.25 ~ 1.25** | **不建議** | — |
| -2.25 ~ -1.25 | 客勝 | 淨勝 1 球（客隊） |
| -3.25 ~ -2.25 | 客勝(-1) | 淨勝 2 球（客隊） |
| ≤ -3.25 | 客勝(-2) | 淨勝 3 球（客隊） |

> 中間區間 **±1.25 以內** 視為方向不明確，系統會建議「不建議」。

### 2️⃣ 入球大細（雙門檻法）

**主隊入球 1.5**：
- 若 `主隊得分 ≤ 1.40` **且** `客隊失球 ≤ 1.40` → **小 1.5**
- 若 `主隊得分 ≥ 1.60` **且** `客隊失球 ≥ 1.60` → **大 1.5**
- 其他情況 → **方向模糊**

**客隊入球 1.5**（對稱邏輯）：
- 若 `客隊得分 ≤ 1.40` **且** `主隊失球 ≤ 1.40` → **小 1.5**
- 若 `客隊得分 ≥ 1.60` **且** `主隊失球 ≥ 1.60` → **大 1.5**

**總入球 2.5**：
- 左右兩邊都是「小」→ **小 2.5**
- 左右兩邊都是「大」→ **大 2.5**
- 否則 → **方向模糊**

### 3️⃣ 波膽推薦

根據預測淨勝球自動生成比分組合（**上限 3:3**）：

| 淨勝球 | 波膽組合 |
|---|---|
| 主淨勝 1 球 | 1:0 / 2:1 / 3:2 |
| 主淨勝 2 球 | 2:0 / 3:1 |
| 主淨勝 3 球 | 3:0 |
| 客淨勝 1 球 | 0:1 / 1:2 / 2:3 |
| 客淨勝 2 球 | 0:2 / 1:3 |
| 客淨勝 3 球 | 0:3 |

> 若賽果為「不建議」，波膽欄會顯示「方向不明，不建議」。

## 🏅 實力評級系統

### 五項 / 六項指標

系統會將每隊的 **進攻、防守、狀態、賠率、轉換**（+ 排名，如有）轉換為 0~100 的百分比：

| 指標 | 計算公式 | 顏色 |
|---|---|---|
| **進攻** | `(xG − 0.5) / 2.0 × 100` | 🔴 紅 `#ff6b6b` |
| **防守** | `(3 − xGA − 0.5) / 2.0 × 100` | 🔵 藍 `#6b9fff` |
| **狀態** | `狀態 / 3.0 × 100` | 🟡 黃 `#fbc02d` |
| **賠率** | `客隊賠率 / (主 + 客賠率) × 100`（主隊反之） | 🟢 綠 `#4caf50` |
| **轉換** | `(得分 + 對方失球) / 轉換總和 × 100` | 🔵 螢光藍 `#00e5ff` |
| **排名** | `對方排名 / (主 + 客排名) × 100` | ⚪ 灰 `#888` |

### 等級對照

| 百分比 | 等級 | 顏色 |
|---|---|---|
| < 20 | E | 銀灰 |
| 20 ~ 40 | D | 銅 |
| 40 ~ 60 | C | 紅 |
| 60 ~ 75 | B | 綠 |
| 75 ~ 85 | A | 藍 |
| 85 ~ 95 | S | 金 |
| ≥ 95 | X | 紫 |

### 戰力總評

```
戰力 = (進攻 + 防守 + 狀態 + 賠率 + 轉換 [+ 排名]) / 6
```

顯示格式：**`戰力: A (84.8)`**（斜體粗體）

## ❓ 常見問題

**Q: 如何取得存取密碼？**

**Q: 首次使用需要密碼嗎？**  
A: 不需要。首次開啟網頁會自動獲得 **1 小時免費使用**，右上角有倒數顯示。免費期結束後才需要輸入密碼。

**Q: 輸入密碼後有時限嗎？**  
A: 沒有。輸入正確密碼後即**永久解鎖**，不會再有任何時間限制。

**Q: 有冇使用教學？**  
A: 有，請睇短片教學 👉 <https://youtube.com/shorts/Xb3Jc_3utFg?si=c_gEf4lHqIbK5nqY>

**Q: 排名不填可以嗎？**  
A: 可以。排名為選填欄位，兩隊都填才會啟用「排名」評分項與六角雷達圖；只填一隊視同未填。

**Q: 為何有時波膽顯示「方向不明，不建議」？**  
A: 當 `diff` 落在 -1.25 ~ 1.25 之間時，系統判斷賽果方向模糊，不給出波膽。

**Q: 轉換（COV）是什麼意思？**  
A: 主隊轉換 = 主隊得分 + 客隊失球；客隊轉換 = 客隊得分 + 主隊失球。反映進攻火力與對方防守漏洞的結合。

**Q: 保存的圖片為何模糊？**  
A: 使用 `scale: 2` 提升解析度，若仍模糊可將 `scale` 改為 `3` 或 `4`（但圖片檔案會變大）。

**Q: 能否完全離線使用？**  
A: 主要功能可離線使用，但 `html2canvas` 需從 CDN 載入。若要完全離線，請將 CDN 檔案下載到本地並改為相對路徑。
